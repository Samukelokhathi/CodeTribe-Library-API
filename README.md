
# 📚 CodeTribe Library API

<img src="https://socialify.git.ci/Samukelokhathi/CodeTribe-Library-API/image?language=1&owner=1&name=1&stargazers=1&theme=Light" alt="CodeTribe-Library-API" width="640" height="320" />

A backend library management API built with Node.js and TypeScript. This project focuses on understanding how REST APIs work, handling HTTP requests, managing library resources, and building backend functionality without relying on Express.

The project was developed as part of my backend learning journey at CodeTribe, helping me practice server-side development, API routing, CRUD operations, and working with TypeScript.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Samukelokhathi/CodeTribe-Library-API.git
```

### Navigate into the Project

```bash
cd CodeTribe-Library-API
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

### Build the Project

```bash
npm run build
```

### Start the Production Server

```bash
npm start
```

> **Note:** Ensure that the scripts in `package.json` match the commands above. Update them if your project uses different scripts.

## 🔄 API Concepts

The project focuses on the following HTTP methods:

| Method | Purpose |
|---|---|
| GET | Retrieve library data |
| POST | Create a new resource |
| PUT | Update an existing resource |
| DELETE | Remove a resource |

> Refer to the implemented routes in the project source code for the exact endpoints and request formats.
